Assistive System

ADECS

Autonomous Anomaly Detection and Elderly Care System with robotic support and multi-sensor monitoring.

The idea.

The ADECS (Anomaly Detection and Elderly Care System) framework is a comprehensive assistive technology designed for continuous monitoring and proactive elder care. At its core is a robotic unit that serves as both a tactile emotional support device and a multi-sensor hub, integrating temperature, motion, touch, and proximity sensors.

Combined with a high-resolution CCTV visual monitoring system, ADECS provides total environmental awareness. The system uses a hybrid edge-cloud architecture where local computing handles real-time sensor fusion for immediate response, while the cloud enables deep multi-modal reasoning and long-term data tracking.

Inside the system.

  • Robotic Hub: Tactile emotional support with multi-sensor integration
  • Visual Network: High-resolution CCTV for behavioral tracking
  • Hybrid Processing: Real-time edge compute + cloud multi-modal reasoning
  • Environmental Intelligence: Real-time perception and anomaly detection
  • Proactive Care: High-speed response with minimal human supervision
